# Windows 本地知识库

桌面版以 Electron 便携程序运行，网页构建保留原有的只读档案与 PWA。打包后的桌面程序从本地加载页面、字体、音频与模型，不需要另装 Node.js、启动开发服务器或登录账户。

## 开发与打包

先安装项目依赖，再在项目根目录执行：

```powershell
npm.cmd run dev:desktop
npm.cmd run check:desktop
npm.cmd run build:desktop
npm.cmd run package:desktop
```

`dev:desktop` 启动 Vite 与开发窗口；`check:desktop` 运行文件仓库自动化检查；`build:desktop` 构建桌面页面；`package:desktop` 使用 Electron Forge 生成 Windows 便携程序目录。开发依赖和 Electron 下载需要联网，完成打包后的本地知识库可离线使用。原网站仍使用 `npm.cmd run build`，内容检查使用 `npm.cmd run check:content`。

本机 PowerShell 请使用 `npm.cmd`；Node.js 安装位置见 `E:\CodexSandbox\AGENT.md`。开发模式的数据在项目根目录 `RhineLabData`，打包版的数据在可执行文件旁。

## 界面与网页版一致

1.1.1 起，客户端首页直接复用网页的完整三维阵列、镜头、开场、详情、查看器和系统设置。点击 ARCHIVE INDEX 打开本地知识库；详情页 EDIT 进入对应文档编辑。关闭知识库返回三维界面。

完整知识库没有 40 篇限制。阵列保留原来的 40 个可见档案槽位；从列表打开其他文档后会将它映射到展陈槽位，空槽位显示新建提示。桌面入口为 `src/desktop-entry.ts`，`src/desktop-main.ts` 是网页入口的桌面适配，共享场景与动画模块；网页入口、数据、样式和动画均未修改。

## 文档在哪里

```text
程序文件夹/
  Rhine Lab … .exe
  resources/ …
  RhineLabData/
    documents/<稳定文档ID>.md
    .trash/<稳定文档ID>.md
    backups/… .md
```

首次空库导入 40 份示例档案。初始化后删空知识库不会再次自动导入。每篇文档是 UTF-8 Markdown，开头的 YAML front matter 保存 ID、标题、分类、排序与时间。标题修改不会更改文件名。正文与排序保存在 Markdown 文件中，不依赖浏览器缓存。

删除先移入回收区，可在界面恢复；永久删除需明确确认。`backups` 用于保留写入前版本，建议另外定期复制整个 `RhineLabData` 到备份位置。不要删除仍需恢复的备份或初始化标记。

程序必须放在当前用户可写目录，例如“文档”中的独立文件夹。遇到只读目录或权限错误时退出程序，将整个程序文件夹移动到可写位置再打开。应用不会静默把文档改存到别处。知识库不支持符号链接或目录联接。

## 编辑、外部修改与迁移

通过左侧列表新建、检索、分类和排序，在编辑区修改标题及 Markdown 正文。保存状态确认成功后再关闭；切换文档或退出时会处理未保存内容。三维阵列展示文档子集，完整知识库由列表访问，不以 40 篇为上限。

可使用其他 Markdown 编辑器打开 `documents` 内的文件。程序监听文件变化，也提供手动刷新入口。外部变化与当前未保存编辑冲突时，先保留需要的草稿，再刷新读取磁盘版本并手动合并；不要通过反复保存覆盖冲突。新增纯 Markdown 文件也可以导入索引；带 front matter 的文件必须使用合法且不重复的 ID。预览支持常用 Markdown，禁用原始 HTML；外部 HTTP / HTTPS 链接使用系统浏览器打开。

搬迁时先关闭程序，再复制**整个程序文件夹，包括 `RhineLabData`**，到另一个可写位置。只有 `.exe` 不构成完整便携程序，运行时资源也必须保留。更新时先备份 `RhineLabData`，再替换程序文件；始终保留原 `RhineLabData` 文件夹。首版没有自动更新或安装器卸载流程。移除程序前请单独保存知识库，删除整个文件夹也会删除其中的数据。

网页设置中提供“导出设置与收藏”和“导入设置与收藏”，客户端提供相应迁移入口。格式为 `{ "version": 1, "settings": { … }, "saved": ["X-001"] }`，大小上限 1 MB。示例档案保留原始编号，因此网页收藏可对应到桌面示例。导入替换偏好与收藏，网页会忽略只存在于客户端的文档编号。JSON 不包含 Markdown 正文，文档迁移请复制 `RhineLabData`。应用不读取其他浏览器的私有配置目录。
